---
name: User experience design approach
description: How this user thinks about player-facing UX — quests as narrative archive, accessible history
type: feedback
---

**Quests are a narrative archive, not just a to-do list.** Completed quests (including the intro sequence) remain accessible and reviewable forever. The intro scene was deliberately designed to land as a pre-completed quest so the player can re-read it at any time.

**Why:** Players may want to revisit information from earlier in the game. The story context is as valuable as the task tracking.

**How to apply:** Design quest UI and data to treat the completed state as a first-class reading experience. Never discard or hide completed quests.
